# 课题要求与可运行 Demo 对照

依据：[研究目标与考核要求](../TASK.md)。运行与结果说明见
[examples/task_demos/README.md](../../examples/task_demos/README.md)。

当前神经网络直接复用 PECJ 原始权重和 SRTFD 原始 GCFAggMVC 类，原自建网络已停用，详见
[RESEARCH_ENGINE.md](../compute/RESEARCH_ENGINE.md)。下述四个轻量 Demo 仍作为独立基线保留。

2026-11-03 已实际解压最新 upstream 包核查，详见
[逐项核查报告](../reports/TASK_PACKAGE_AUDIT_2026-11-03.md)。当前包已有可运行异常检测与 Demo，
但自动双模切换、原网络分阶段持续学习/伪标签 Demo、CXL 与第三方验收尚未完成。

## 当前交付范围

`sage-tsdb-pecj-component-0.2.0-linux-x86_64.tar.gz` 的打包脚本设置
`SAGE_TSDB_ENABLE_SRTFD=OFF`，所以现有二进制包只提供 PECJ 计算入口。
包里有异常诊断头文件不表示提供了对应可运行实现。

原 0.2.0 包未启用神经诊断。当前 upstream 组件已实现 TorchScript 批次推断与结果写库；
训练与导出由 Python 接入层调用原始 SRTFD 网络完成。`External` 后端仍未实现。

原 CLI 默认完整窗口批处理。当前接入层支持独立到达时间，并合并 S/R 的到达顺序；
原生 AI 演示通过提前水位线实际触发原模型。四个轻量 Demo 仍只声明其各自的基线能力。

## 四个演示

| Demo | 对应课题 | 可运行内容 | 主要证据 | 能力边界 |
|---|---|---|---|---|
| `join`：迟到与窗口 Join | 乱序流高效窗口聚合，研究内容（1）的数据问题 | 真实 IAWJ；不同等待预算的可见数据；独立全量/可见真值 | 匹配数、缺失对数、相对误差、引擎与进程耗时 | 未实现或验证 PDA 后验补偿 |
| `drift`：工况漂移与簇演化 | 总体目标中的运行时自适应聚类 | EMA 微簇、紧凑新颖缓冲、旧工况复用、容量淘汰 | 误报率、召回率、簇创建与 ID 记录 | 属于独立在线聚类基线，未实现神经网络双模后验 |
| `continual`：增量故障诊断 | 研究内容（4）持续学习、核心集、均衡采样、伪标签 | 稀疏标签、类均衡几何核心集、最近类中心、门控伪标签 | 阶段留出集逐类召回、旧类遗忘、新类学习、记忆上限 | 原型级样本回放，不是 SRTFD 神经网络训练 |
| `warning`：Join 到提前预警 | 考核项中的流式故障提前预警 | 真实 Join 计数 + 应用层特征对齐 + 正常标定 + 连续超限告警 | 数据缺失抑制、决策时间、故障真值和提前量 | 合成时钟，CSV 落盘；未接真实设备、达梦或 CXL |

四个示例分别展示“数据不完整”“工况变化”“故障类别变化”“预警链路”，可单独演示或
按该顺序串讲。它们提供当前可运行的原型与基线，不覆盖全部研究算法和考核条件。

## 后续实现状态与仍需验证的能力

| 课题能力 | 当前实现 | 仍需验证 |
|---|---|---|
| PDA 后验近似与迟到补偿 | 新 Python 引擎实现 Poisson/LogNormal 概率模型、双时间、截止时刻、缺失补偿和预测区间 | 相关到达/键相关延迟、更多数据集、与 k-slack/Watermark 对照 |
| VI 自动参数优化 | 均值场高斯、真实 ELBO、重参数化梯度、在线优化与参数轨迹 | 长期收敛、参数敏感性和目标部署延迟 |
| EMA/MLP 双模后验 | 自建 MLP 已删除；PECJ 原始 linearVAE / AI 与解析 EMA/VI 可独立运行，但没有自动切换控制器 | 补齐按延迟方差/乱序比例切换的接入与 Demo，再验证精度、区间和开销 |
| 持续学习诊断 | 直接导入原 GCFAggMVC；检查点、继续训练与 TorchScript/C++ 推断可运行；主神经 Demo 为全标注训练 | 补齐 TEP 分阶段增量、稀缺标签/伪标签 Demo；评测正常类误报、新类学习和旧类遗忘 |
| CXL 异构架构 | 尚未接入真实 CXL 硬件 | 在真实硬件上测接入吞吐、延迟、故障提前量，并形成第三方测试报告 |

原 PECJ 默认包的 AI 资产未随包提供；upstream 新包已附带并验证 linearVAE 模型。没有模型文件与结果
验证时，不应使用它们的名称宣称已经满足 VI 或双模要求。Python Demo 的均衡核心集
实现也不能直接替代项目完整持续学习模型。

## 交付方式

现有 0.2.0 压缩包无需重新编译即可作为 `join`、`warning` 的依赖。
新增示例可作为补充包与其一起提供，或从源码直接运行。
源码重新执行组件打包后，示例会随安装进入 `share/sageTSDB/task_demos/`，此说明进入
`share/doc/sageTSDB/examples/`。Python 实现作为独立演示层，不改变 PECJ C ABI。
